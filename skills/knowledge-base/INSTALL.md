This skill wraps the standalone `knowledge-base` project. The skill body references
the project via the `$KNOWLEDGE_BASE_HOME` env var, with a default of `~/projects/knowledge-base`.

## Setup

```bash
# 1. Clone the project (skip if you already have it)
git clone https://github.com/<your-github-org>/knowledge-base.git ~/projects/knowledge-base

# 2. Install dependencies
cd ~/projects/knowledge-base && npm install

# 3. (Optional) Pin the location with an env var
export KNOWLEDGE_BASE_HOME=~/projects/knowledge-base
# Add the above to ~/.bashrc or ~/.zshrc to make it permanent.
```
